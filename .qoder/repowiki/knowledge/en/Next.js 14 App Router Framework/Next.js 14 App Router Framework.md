Core framework powering the Vaya application with App Router architecture. Used for server-side rendering, API routes (/api/chat, /api/calculate, /api/policy), and static site generation capabilities. The project leverages Next.js 14's modern features including React Server Components and streaming responses via Server-Sent Events (SSE) for real-time chat functionality.
