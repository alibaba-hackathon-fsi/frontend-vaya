Single-tenant Next.js 14 App Router application rooted at `src/app/` with three top-level routes: the home page (`page.tsx`), the `/chat` advisor flow, and shared layout (`layout.tsx`) that wires fonts, `<I18nProvider>`, `<Navbar>`, and metadata. Components live under `src/components/` (UI primitives like Navbar, Hero, MarketsSection, ChatAdvisor, and hand-written SVG chart components in `charts/`). Business logic is isolated in `src/lib/loanEngine.ts` (deterministic scoring/recommendation) and static data in `src/data/banks.ts`. Internationalization is a lightweight React context in `src/i18n/` supporting EN/VI/ZH persisted to `localStorage`. Styling uses Tailwind CSS with a minimal config; the design system (colors, typography, square corners) lives in `src/app/globals.css` as CSS custom properties rather than Tailwind utilities. The project is configured for strict TypeScript (`strict: true`, `noEmit`, `moduleResolution: bundler`) and can be exported as a fully static site by enabling `output: 'export'` in `next.config.mjs`.
