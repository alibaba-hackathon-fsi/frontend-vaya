Install dependencies with `npm install`, then run development server via `npm run dev` (http://localhost:3000). Production build is `npm run build && npm start`. For static export (GitHub Pages/Netlify), uncomment `output: 'export'` in `next.config.mjs` before building to produce an `out/` folder. ESLint is disabled during builds (`eslint.ignoreDuringBuilds: true`) so lint nitpicks do not block production output.
