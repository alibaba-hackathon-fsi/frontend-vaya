Three co-located data modules that serve as the declarative input layer for the decision engine in `@/lib/engine`. `intakeQuestions.ts` defines the `IntakeQuestion` schema and an ordered `INTAKE_QUESTIONS` array plus a `getNextQuestion` helper that walks required fields to drive the multi-stage interview flow. `checklists.ts` exports `DOCUMENT_CHECKLISTS`, each item typed against `ChecklistItem` from `@/lib/engine/checklistEngine`, with conditional applicability expressed via `appliesToIncomeProof` arrays and category tags (`IDENTITY`, `INCOME`, `COLLATERAL`, `PURPOSE`). `loanPackages.ts` exports `LOAN_PACKAGES`, typed against `LoanPackageRecord` from `@/lib/engine/types`, enumerating bank products keyed by `muc_dich` (purpose) with numeric rate/limit/term bounds and boolean flags (`online_application`, `ekyc`, `fast_approval`, `no_cic_required`). All three files are pure data — no runtime computation beyond the single `getNextQuestion` selector — and depend only on shared engine types, keeping business rules in the engine while this module owns the content.
