All files under src/data are plain TypeScript modules exporting immutable configuration objects typed against shared engine types (e.g. LoanProduct from @/lib/engine/types). The products subdirectory acts as a small registry: index.ts aggregates product definitions (currently only vietcombank) and re-exports query helpers (getAllProducts, getProduct, getProductsByBank, getProductsByPurpose). Other top-level data files follow the same pattern — each file owns one domain of business configuration (eligibilityRules, riskRules, intakeQuestions, checklists, loanPackages, scenarios) and is imported directly by consumers rather than through a central barrel. This keeps the data layer decoupled from UI and logic layers while providing a single source of truth for all rule-based decisions.
