Single-file module that defines a Zod schema (`LoanProfileSchema`) for the `LoanProfileInput` type, exports two VND constants (`MAX_LOAN_AMOUNT_VND`, `MAX_MONTHLY_INCOME_VND`) as trust-boundary limits, and exposes a single `validateProfile(raw: unknown)` function. The function is the explicit boundary between untrusted external input (LLM/user) and pure decision-engine functions: it runs `safeParse`, normalizes error messages, then performs an additional required-fields check against `REQUIRED_FOR_CALCULATION` to distinguish structural validity from calculation readiness. The return shape `{ profile, result }` with a `ValidationResult` interface separates the parsed payload from validation metadata.
