The root is a single Next.js 14 App Router project (TypeScript + React) that co-locates all layers: `src/app/api` exposes the API routes (loan calculation, SSE chat advisory, RAG policy query), while shared business logic lives in sibling packages `lib_engine`, `lib_ai`, `lib_validation`, and `data`. The `tsconfig.json` path alias `@/* → ./src/*` centralizes imports, and `next.config.mjs` keeps builds strict-mode with ESLint ignored during build for resilience. Children communicate through typed TypeScript modules rather than HTTP calls — the API routes import from `lib_*` and `data` directly, forming a unidirectional flow: API Routes → lib_ai → lib_engine → data, with lib_validation guarding every inbound profile.
